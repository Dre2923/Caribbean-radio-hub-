# Caribbean Radio & Events Platform

[![Backend CI](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/backend-ci.yml/badge.svg)](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/backend-ci.yml)

Premium, production-grade Caribbean radio, events, voice-control,
advertising, discovery, and community platform for Android, iPhone/iPad,
and Windows (macOS deferred).

Built one numbered step at a time — see [`docs/BUILD_MANIFEST.md`](docs/BUILD_MANIFEST.md)
for the full 64-step sequence, launch-country list, and design direction.

## Current status

Steps 01–04 (Foundation & Backend: bootstrap, core schema, authentication,
observability) are built, security-reviewed, and CI-verified on every push.
See [`backend/README.md`](backend/README.md) for details and
[`docs/BUILD_MANIFEST.md`](docs/BUILD_MANIFEST.md) for the full progress log.
