# Caribbean Radio & Events Platform

[![Backend CI](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/backend-ci.yml/badge.svg)](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/backend-ci.yml)
[![Admin Dashboard CI](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/admin-dashboard-ci.yml/badge.svg)](https://github.com/Dre2923/Caribbean-radio-hub-/actions/workflows/admin-dashboard-ci.yml)

Premium, production-grade Caribbean radio, events, voice-control,
advertising, discovery, and community platform for Android, iPhone/iPad,
and Windows (macOS deferred).

Built one numbered step at a time — see [`docs/BUILD_MANIFEST.md`](docs/BUILD_MANIFEST.md)
for the full 64-step sequence, launch-country list, and design direction.
Architecture decisions and research for Steps 27-64 are documented in
[`docs/ARCHITECTURE_PLAN.md`](docs/ARCHITECTURE_PLAN.md).

## Current status

Steps 01–31 are built, verified, and CI-verified on every push — the
Foundation/Backend, Caribbean Radio Master Catalog, Stream Reliability,
and Events Database buckets are complete, and the Admin Dashboard bucket
(Steps 31-33) is underway. See [`backend/README.md`](backend/README.md)
for the API and [`admin-dashboard/README.md`](admin-dashboard/README.md)
for the admin web console, and
[`docs/BUILD_MANIFEST.md`](docs/BUILD_MANIFEST.md) for the full progress
log.
